# Weara — Find Any Outfit
Android visual fashion discovery app by Ecrin Labs.

## Current build
- Camera capture via CameraX
- Gallery picker
- On-device ML Kit object detection (no paid AI API)
- Multi-item result cards
- Local history/favorites foundation
- External shopping search links
- Jetpack Compose UI
- GitHub Actions APK + AAB builds

## Cost
No paid AI API is required by the app.

## Build
`./gradlew assembleDebug`
